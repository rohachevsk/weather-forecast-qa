Checklist — City Search

Основная функциональность

 Поиск существующего города
 Поиск несуществующего города
 Поиск города с несколькими словами в названии
 Поиск города с использованием частичного названия
 Поиск города в любом регистре (Kyiv, kyiv, KYIV)
 Поиск города с опечаткой
 Поиск города при неправильной раскладке клавиатуры
 Поиск города на разных языках
 Поиск города при вводе названия на двух языках одновременно

Некорректные данные

 Поиск с цифрами
 Поиск со специальными символами
 Поиск с эмодзи
 Пустой поисковый запрос
 Поисковый запрос, состоящий только из пробелов
 Пробелы в начале поискового запроса
 Пробелы в конце поискового запроса
 Очень длинный поисковый запрос

Границы

 Проверить минимальное количество символов для поиска
 Проверить максимальную допустимую длину поискового запроса
 Проверить поведение при вводе сверх максимальной длины

Результат поиска

 Проверить, что найденный город отображается корректно
 Проверить, что после выбора/поиска города отображается погода именно выбранного города
 Проверить, что при несуществующем городе отображается корректное сообщение об ошибке
 Проверить, что предыдущий город не подменяется некорректными данными после неудачного поиска
