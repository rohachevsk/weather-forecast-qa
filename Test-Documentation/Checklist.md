# Checklist — City Search

## 1. Основная функциональность

* [x] Поиск существующего города
* [x] Поиск несуществующего города
* [x] Поиск города с несколькими словами в названии
* [x] Поиск города с использованием частичного названия
* [x] Поиск города в любом регистре (`Kyiv`, `kyiv`, `KYIV`)
* [x] Поиск города с опечаткой
* [x] Поиск города при неправильной раскладке клавиатуры
* [x] Поиск города на разных языках
* [x] Поиск города при вводе названия на двух языках одновременно

## 2. Некорректные данные

* [x] Поиск с цифрами
* [x] Поиск со специальными символами
* [x] Поиск с эмодзи
* [x] Пустой поисковый запрос
* [x] Поисковый запрос, состоящий только из пробелов
* [x] Пробелы в начале поискового запроса
* [x] Пробелы в конце поискового запроса
* [x] Очень длинный поисковый запрос

## 3. Границы

* [x] Проверить минимальное количество символов для поиска
* [x] Проверить максимальную допустимую длину поискового запроса
* [x] Проверить поведение при вводе сверх максимальной длины

## 4. Результат поиска

* [x] Проверить, что найденный город отображается корректно
* [x] Проверить, что после выбора/поиска города отображается погода именно выбранного города
* [x] Проверить, что при несуществующем городе отображается корректное сообщение об ошибке
* [x] Проверить, что предыдущий город не подменяется некорректными данными после неудачного поиска
