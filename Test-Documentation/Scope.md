# Test Scope

## Project Overview

* **Project:** Weather Forecast
* **Testing Type:** Manual Web Testing
* **Tester:** Rohachevsk
* **Environment:** Windows 11, Chrome, Production

## Testing Objective

The objective of testing was to verify the main functionality, user interface, input validation, localization, and accuracy of weather data in the Weather Forecast application.

## In Scope

The following functionality was included in testing:

* City search
* Search input validation
* Geolocation
* Current weather information
* Hourly forecast
* 3-day and 7-day forecast
* Weather charts
* Radar / weather map
* Cloudiness, Visibility and UV Index
* Interface localization
* Dark / Light theme
* Favorites
* Login interface

## Testing Areas

The following testing approaches were applied:

* Functional Testing
* UI Testing
* Negative Testing
* Input Validation
* Boundary Value Analysis
* Localization Testing
* Exploratory Testing
* Data Accuracy Validation

## Out of Scope

The following areas were not included in this testing project:

* Backend source code testing
* Performance and load testing
* Security testing
* Automated testing
* Mobile application testing
* Cross-browser testing
* Fixing identified defects
